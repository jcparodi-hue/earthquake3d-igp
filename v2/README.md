# EARTHQUAKE 3D v2.0

Entorno independiente para desarrollar y validar EARTHQUAKE 3D v2.0.

## Clasificación

Modelo experimental de investigación y vigilancia sísmica regional.

No constituye una alerta oficial, una predicción determinista ni sustituye la información del IGP/CENSIS y otras autoridades competentes.

## Objetivos iniciales

- Preservar el Transfer Pressure Map como matriz conceptual original.
- Digitalizar corredores, nodos D, puntos X, volcanes y bifurcaciones.
- Integrar eventos sísmicos de fuentes oficiales.
- Implementar forecasts regionales experimentales con una vigencia máxima de 168 horas.
- Mantener separados los datos observados, cálculos reproducibles, reglas experimentales e hipótesis físicas.
- Registrar todas las versiones, reajustes, aciertos y fallos.
- Validar cada componente frente a modelos de referencia.

## Estado

Fase inicial de estructuración técnica.
