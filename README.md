# IGP Peru para Earthquake 3D

Proyecto gratuito que convierte el feed público curado del IGP al formato CSV leído por Earthquake 3D.

## Publicación
1. Cree un repositorio público en GitHub.
2. Suba todos los archivos conservando las carpetas.
3. En Settings > Pages, seleccione Deploy from a branch, `main`, carpeta `/docs`.
4. En Actions, ejecute `Actualizar feed IGP para Earthquake 3D` una vez.

La dirección publicada será:
`https://USUARIO.github.io/NOMBRE-REPOSITORIO/igp_7dias_eq3d.csv`

En Earthquake 3D use Online CSV File:
- Domain Name: `USUARIO.github.io`
- File Name and Path: `/NOMBRE-REPOSITORIO/igp_7dias_eq3d.csv`

Solo conserva eventos de los siete días anteriores al momento de ejecución. La actualización programada es cada 15 minutos. Proyecto independiente, no afiliado al IGP y no es una alerta temprana.
